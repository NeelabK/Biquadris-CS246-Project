# Biquadris

Biquadris is a two-player Tetris-inspired game developed in C++ as the final project for CS 246: Object-Oriented Software Development at the University of Waterloo.

The project was designed using object-oriented principles with an emphasis on modularity, low coupling, and high cohesion. The game supports both a console interface and a graphical interface, with multiple difficulty levels and special effects that players can trigger against one another.

Due to University of Waterloo academic integrity policies, the complete source code is not publicly available. Selected components, documentation, and design artifacts are included in this repository. Full source code can be discussed or shown privately upon request.

## Features

- Two-player Tetris-style gameplay
- Multiple difficulty levels
- Console and graphical interfaces
- Row-clearing and scoring system
- Special effects that can be applied to an opponent
- Persistent high-score tracking
- Restart and replay functionality
- Modular object-oriented C++ design

## Design

The project was structured around reusable and maintainable C++ components. The design emphasizes:

- encapsulation
- low coupling
- high cohesion
- separation of game logic and presentation
- extensibility for additional levels and game mechanics
